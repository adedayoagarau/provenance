System Architecture Overview

The platform consists of three primary layers: the ingestion layer, the processing layer, and the serving layer. The ingestion layer uses Apache Kafka for real-time event streaming, supporting up to 2 million events per second with at-least-once delivery guarantees. Events are partitioned by tenant ID to ensure ordering within a single tenants data stream. The processing layer employs Apache Flink for stateful stream processing, performing enrichment, aggregation, and anomaly detection in near real-time. Results are persisted to both a PostgreSQL database for transactional queries and an Elasticsearch cluster for full-text search.
