Database Schema Design

The users table serves as the primary entity table with columns: id (UUID, primary key), email (VARCHAR 255, unique, not null), password_hash (VARCHAR 255, not null), created_at (TIMESTAMP WITH TIME ZONE, default NOW), updated_at (TIMESTAMP WITH TIME ZONE). A GIN index on the metadata JSONB column enables efficient querying of user attributes. The sessions table references users via a foreign key with CASCADE delete behavior. Connection pooling is managed via PgBouncer with a maximum of 200 connections per pool and transaction-level pooling mode.
